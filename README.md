# AZ-900 Practice Exam — 200 Questions
A collection of 200 English practice questions for Microsoft Azure Fundamentals (AZ-900) preparation.

I earned my Azure Fundamentals certification after two weeks of preparation: one week studying the topics and one week focused entirely on practice questions.

I'm sharing this resource to help others review the concepts and prepare for the exam.
